# Apex Admin

Публичный сайт и кабинет рекламодателя Apexmedia — платформы рекламы на экранах тележек в супермаркетах. React, TypeScript, Vite и Supabase.

- [Справочник БД](docs/DATABASE_SCHEMA.md) — таблицы, поля, связи, представления и прикладные RPC.

Рабочий сайт: https://apexmedia.kz. Документация фиксирует состояние `main` на 7 октября 2026 года; пароли и ключи передаются отдельно.

## Запуск

```powershell
npm ci
Copy-Item .env.example .env.local
# Заполнить .env.local, затем:
npm run dev
```

Основной проект: http://localhost:5173.

Доступные экраны:

| Путь | Экран |
| --- | --- |
| `/` | Лендинг |
| `/login` | Вход |
| `/signup` | Регистрация |
| `/signup/verify` | Подтверждение email кодом; телефон подтверждается следующим этапом регистрации |
| `/signup/profile` | Данные рекламодателя: ФИО, БИН, компания |
| `/reset-password` | Восстановление пароля: ввод почты или телефона |
| `/reset-password/code` | Восстановление пароля: ввод кода |
| `/reset-password/new` | Установка нового пароля |
| `/reset-password/done` | Подтверждение смены пароля |
| `/privacy` | Политика конфиденциальности |
| `/offer` | Публичная оферта |
| `/cabinet` | Главная кабинета |
| `/cabinet/campaigns` | Кампании и мастер создания |
| `/cabinet/analytics` | Аналитика магазинов |
| `/cabinet/profile` | Профиль и смена контактов |

Полная карта маршрутов и статус ещё не реализованных страниц — в техническом обзоре.

Экраны используют общую дизайн-систему, светлую и тёмную тему, а также переводы ru/kk/en.
Вход и регистрация подключены к Supabase Auth. При новой регистрации обязательны email и телефон с подтверждением обоих контактов. На экране входа можно запросить код вместо пароля. SMS OTP отправляется через настроенный Send SMS Hook: Edge Function `send-sms` передаёт сообщение в Kazinfoteh по JSON API. Секреты SMS-провайдера остаются на сервере; ограничения поддерживаемых номеров описаны в техническом обзоре.

Для локального запуска скопируйте `.env.example` в `.env.local` и укажите `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`. Секреты SMS-провайдера не добавляйте в frontend env.

```powershell
npm run lint
npm run build
npm run preview
```

Используется Node.js 20.19+ или 22.12+ и npm. Зависимости закреплены в `package-lock.json`.

## Первоначальные worktree трёх агентов

Ниже сохранена схема первоначального распределения работы. Наличие worktree не означает, что агенты сейчас запущены.

Все пути ниже указаны относительно основного каталога `apex-admin`.

| Назначение | Ветка | Каталог | Команда запуска в своем каталоге |
| --- | --- | --- | --- |
| Интеграция | `main` | `.` | `npm run dev -- --port 5173 --strictPort` |
| Агент 1 | `agent/1` | `../apex-admin-worktrees/agent-1` | `npm run dev -- --port 5174 --strictPort` |
| Агент 2 | `agent/2` | `../apex-admin-worktrees/agent-2` | `npm run dev -- --port 5175 --strictPort` |
| Агент 3 | `agent/3` | `../apex-admin-worktrees/agent-3` | `npm run dev -- --port 5176 --strictPort` |

Каждый worktree имеет собственные исходники и `node_modules`, но общую историю Git. Проверить рабочие копии: `git worktree list`.

После получения HTML координатор распределяет экраны и согласует общие компоненты. Агенты делают коммиты в своих ветках; координатор проверяет результат и объединяет изменения в `main`.

Правила совместной работы находятся в `AGENTS.md`.
